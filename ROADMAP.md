# ROADMAP — улучшения «Амур Атласа»

Приоритизировано по «эффект / усилия». Делать сверху вниз, одну фичу за подход, коммит на каждую. У каждой — зачем и критерий готовности (DoD).

### Как работать
1. Открыть репозиторий в Claude Code, дать прочитать `CLAUDE.md` и `index.html`.
2. Взять пункт из Этапа 1, реализовать, `git diff` → коммит.
3. Проверить в браузере (можно через `claude-in-chrome`), затем следующий пункт.
4. Модель: по умолчанию Sonnet, на сложных местах — Opus.
