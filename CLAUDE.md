# Амур Атлас — гид по Благовещенску (проектная память)

Одностраничный туристический сайт-гид по городу **Благовещенск (Амурская обл., Россия)** — на Амуре напротив китайского Хэйхэ. Автор проекта: ИИщенко LAB.

## Что это технически
- **`index.html`** — весь HTML, CSS и JS внутри. Сборки нет (никакого npm/build).
- **`lang-en.js`, `lang-zh.js`** — словари переводов `window.EN` и `window.ZH` (с 23.07.2026, мультиязычность RU/EN). Вынесен отдельно, чтобы не раздувать index.html и чтобы перевод правился изолированно. Подключён `<script src>` в head. Это осознанное послабление правила «единый файл» ради поддерживаемости словаря.
- **`en/index.html` и `cn/index.html`** — статические языковые версии, собираются скриптом `build/build-lang.js` из `index.html`. Руками не править: пересборка затрёт.
- **`assets/photo/`** — 18 фотографий (афиша, эпохи истории, главы прогулки), скачаны с Викисклада и пережаты в 900 px. Отдаются с нашего домена.
- Внешние зависимости через CDN: Leaflet 1.9.4 (карта), тайлы OpenStreetMap, Google Fonts (Bitter + Golos Text), часть фото галереи с Wikimedia Commons. **Новые картинки класть в `assets/photo`, а не хотлинкить.**
- **Переходов на сторонние ресурсы в интерфейсе нет** (решение Евгения 20.08.2026). Кнопка «подробнее →» у событий снята вместе с механикой. Ссылки наружу не добавлять — кроме нашего Telegram в подвале.

## Мультиязычность (i18n) — как устроена
- Кнопка RU/EN в шапке, выбор в localStorage `atlas-lang`, ранний скрипт в head ставит `<html lang>` до отрисовки.
- Движок `applyLang` в index.html: обходит текстовые элементы по списку `I18N_SEL`, запоминает русский оригинал в `data-ru`, подменяет по совпадению текста из `window.EN`. **Нет ключа → остаётся русский (безопасный fallback), ничего не ломается.** Числа/цены не трогаются — они в отдельных классах (`.stat-num`, `.kpi`, `.hh-total .big` и т.п.), их нет в `I18N_SEL`.
- Ключ словаря = русский `innerHTML` элемента (со схлопнутыми пробелами). Значение — английский `innerHTML` (теги `<em>/<br>/<span>` сохраняются).
- **Статус:** переведён каркас (шапка, hero, заголовки/лиды всех секций, футер, метатеги). Глубокие тексты (карточки, FAQ, факты, кухня, история, Хэйхэ, канатка, сторителлинг) и **динамика** (попапы точек, план маршрута, события, калькулятор Хэйхэ — перерисовываются из JS-массивов) — дозаполняются в `lang-en.js` + хук `window.renderDynamicI18n`. Селекторы под них уже в `I18N_SEL`.
- **中文 есть с 20.08.2026** — `lang-zh.js`, 586 ключей, страница `/cn/`. Перевод машинный, **носителем не вычитан** (задача в ROADMAP, этап 5).
- Языковые версии — отдельные URL с `hreflang`: до этого английский жил только в браузере и роботы его не видели. На статических страницах язык задаёт `window.ATLAS_STATIC`, localStorage его не перебивает, кнопка языка ведёт по кругу RU → EN → 中文.
- **Калькулятор поездки в Хэйхэ на `/en/` и `/cn/` снят** (решение Евгения 20.08.2026): он считает поездку русского в Китай, гостю из Хэйхэ считать нечего. Снимает сборщик, удаляя `.hh-grid`; в самом калькуляторе стоит страховка `if(!el('hh-size'))return`. Остальное в секции — виза, переправы, памятки — остаётся.
- Подписи картинок (`alt`) движок в браузере не переводит, он ходит по текстовым узлам. Их переводит сборщик языковых версий.
- Хостинг: **GitHub Pages**, репозиторий `Evgeniy79638134017/blagoveshchensk-atlas`, ветка `main`, корень. Живёт по `https://evgeniy79638134017.github.io/blagoveshchensk-atlas/`.

## Жёсткие правила (не ломать)
- Держим **единый `index.html`** как единственный источник: весь JS/CSS внутри, никакой сборки для деплоя. Языковые версии — производные, их пересобирает `node build/build-lang.js` **после каждой правки главной страницы**, иначе отстанут.
- Пути к ресурсам, которые собираются в JS-шаблонах, писать **от корня** (`/assets/...`): на `/en/` и `/cn/` относительные ищут файлы в подпапке языка.
- **Не сломать существующее:** интерактивную карту (Leaflet), конструктор маршрута (`renderPlan`), ленту событий, счётчики, секцию «Любопытное».
- Светлая тема — по умолчанию; с 23.07.2026 есть тёмная (кнопка в шапке, `html[data-theme="dark"]` переопределяет токены, выбор в localStorage `atlas-theme`, тайлы карты переключаются light_all/dark_all). Токены в `:root` (`--bg #FAF8F3`, `--teal #0E9A93`, `--amber #E0872B`); служебные: `--on-ink` (текст на кнопках цвета --ink), `--nav-bg`, `--foot-bg`. Новые компоненты обязаны работать в обеих темах.
- **Шрифты (сменены 20.08.2026): Bitter (заголовки, засечный) + Golos Text (текст).** Прежняя пара Space Grotesk + Inter снята по двум причинам: **Space Grotesk не поддерживает кириллицу** (подсеты latin / latin-ext / vietnamese), поэтому все русские заголовки уезжали во фолбэк и страница фактически была целиком на Inter; а Inter — дефолтный выбор, который визуальный антинейрослоп-фильтр помечает как отсутствие решения. Golos Text спроектирован под кириллицу, Bitter её поддерживает. Трекинг заголовков ослаблен до −0.005em: засечному шрифту не нужно такое поджатие, как гротеску. **Space Grotesk не возвращать.**
- Палитра категорий карты — набор **Okabe-Ito (colorblind-safe)**: `--c-nat #009E73`, `--c-sea #2E9AD1`, `--c-his #C56AA0`, `--c-gas #E69F00`, `--c-spa #D55E00`, `--c-city #0072B2`. Менять — только сохраняя контраст.

## Структура данных (в `<script>` внизу)
- `POINTS[]` — 23 точки карты: `{id,name,lat,lng,cat,desc,img?}`. Категории: nat/sea/his/gas/spa/city.
- `ACT[]` — активности для конструктора маршрута (теги, интересы, сезон, стоимость).
- `FALLBACK_EVENTS[]` — встроенная афиша; Google Sheets подключается через `SHEET_CSV_URL` (публикация листа в CSV), парсер `parseCsv` в JS.
- `ERAS[]`, `DISHES[]` — история и кухня. Факты «Любопытного» — статичный HTML в секции `#facts`.
- Модель бюджета в `renderPlan()`: `дневной(бюджет×дни×чел) + проживание(ночи×номера×3800×сезон) + активности(Σ×чел) + дорога(чел×14000)`.

## Точность (важно — уже ловили ошибки)
- **Координаты точек — только из Wikidata (P625) / OpenStreetMap / Википедии, не на глаз.** Центр города и набережная — широта ~50.256–50.262 N.
- **Фото с Commons проверять по категории/описанию, не по имени файла** (были подмены: «собор Благовещения» → оказался Воронеж). Брать из категорий, привязанных к городу.
- **Любые цифры/годы сверять по источникам** перед публикацией.

## Рабочий цикл
- Одна фича за раз → просмотр `git diff` → коммит → проверка в браузере.
- Локальный предпросмотр: `python -m http.server 8765 --directory .` (в проекте Главный есть `.claude/launch.json`, конфигурация `atlas`).
- Проверка: замеры через браузерную панель (загрузка картинок, горизонтальный скролл, консоль, языки). Скриншоты в панели могут не рисоваться — тогда смотреть глазами на localhost.
- **Деплой:** запушить в репозиторий (или на GitHub: Add file → Upload files, перезалить `index.html`) — Pages обновится за 1–2 минуты.

## Визуальный антинейрослоп — проход 20.08.2026

Сайт прогнан по `ASSETS/Визуальный_антинейрослоп.txt` (фильтр появился 13.08.2026, позже сборки сайта). Что снято и **не возвращать**:

- **Градиентная заливка текста** (`-webkit-text-fill-color:transparent`) была на акценте в h1 и в заголовке подвала — клише 2023 года. Теперь плоский цвет.
- **Две размытые градиентные кляксы** (`.hero-blob`) в hero — метка «нейросетевого» визуала. Удалены вместе с CSS.
- **Появления при прокрутке**: было 122 элемента с `.fade`, оставлено 6 (hero-фото, четыре счётчика, крупная плитка бенто) — три акцентных момента. Длительность .7s → .4s. Новым блокам `.fade` по умолчанию НЕ давать.
- **Уровни тени**: было три в покое (`--sh-sm` карточки, `--sh` панели, `--sh-lg` hero). `--sh-sm` снят в `none` — карточки держатся рамкой; осталось два уровня. Шапка при прокрутке переведена на `--sh`.
- **Ховеры** уведены под `@media (hover:hover) and (pointer:fine)` — на тач-экране `:hover` срабатывает по тапу и залипает. Новые ховеры добавлять **внутрь этого блока**, он в конце стилей.
- **Ритм секций**: появились `.s-tight` (4.2rem) и `.s-roomy` (9rem) — одинаковые отступы у всех секций фильтр считает отсутствием дыхания.

Проверено ложных срабатываний, которые править НЕ надо: скругление 12px стоит только на пяти иконочных квадратах 38–42 px, где оно пропорционально размеру, а не «12px у всего»; стекло (`backdrop-filter`) — на шапке, бейдже поверх фото и лайтбоксе, то есть везде, где за ним реально что-то есть.

## Афиша: разметку надо обновлять, она не самоочищается

Лента событий на странице отбрасывает прошедшее сама, в браузере. **Разметка
schema.org этого не умеет** — она лежит статикой и через неделю начинает
показывать поиску истёкшие события, а Google на это перестаёт выводить блок.

Поймано 31.08.2026: в ленте было 9 событий, в разметке 10 — гастрофестиваль
29 августа со страницы ушёл, из разметки нет.

Обновлять так (правила те же, что в браузере: ежегодные катятся на следующий
год, прошедшие разовые выбрасываются):

```
node build/refresh-events.js 2026-08-31
node build/build-lang.js 2026-08-31
```

Скрипт заодно правит `dateModified` в разметке, строку «Факты сверены и
обновлены …» в подвале **и ключ этой строки в обоих словарях** — иначе при
смене даты ключ уезжает и строка на языковых версиях остаётся русской.

Разумная периодичность — раз в месяц и после каждой правки афиши.

## Языковые версии — как устроены (с 20.08.2026)

`/en/` и `/cn/` — **статические страницы**, а не режим в браузере. Причина: движок `applyLang` включается по отметке в localStorage, у поискового робота её нет, поэтому для Яндекса, Google и ответов нейросетей английской версии не существовало вовсе.

- Сборка: `node build/build-lang.js`. Берёт `index.html`, применяет тот же словарь по тем же `I18N_SEL`, переводит атрибуты `alt`, пересобирает FAQ-разметку из уже переведённого DOM (микроразметка обязана дословно повторять видимый текст), подставляет `hreflang`, переписывает пути на корневые, собирает `sitemap.xml` и **снимает калькулятор поездки в Хэйхэ**: он считает поездку русского в Китай, гостю из Хэйхэ считать нечего.
- Язык страницы задаёт `window.ATLAS_STATIC`, localStorage его не перебивает. Кнопка языка на статических версиях — переход по адресу, по кругу RU → EN → 中文.
- Китайский словарь собирается `node build/make-zh.js` из `build/zh/*.json`. Связка через английское значение: русский ключ → английский текст → китайский перевод. Значения без латиницы (цены, единицы) переносятся как есть.
- **⚠️ Китайский перевод машинный, носителем не вычитан.**

### Грабли, которые уже стоили времени

- `initLang()` вызывался **до** объявления `let LANG` и падал в TDZ. Слушатель на кнопку успевал навеситься — поэтому переключение работало и ошибку никто не замечал, — а `applyLang(LANG)` уже не выполнялся, и сохранённый выбор EN при загрузке не применялся. Вызов теперь ниже объявлений, **выше не поднимать**.
- `window.hhCalc` вызывался из `renderDynamicI18n`, но **никогда не присваивался** — калькулятор не перерисовывался при смене языка. Присвоение в конце его IIFE, не удалять.
- `T()` читает `window.__lang`. Его надо выставлять **до** вызова перерисовки, иначе динамика отрисуется по-русски поверх переведённой страницы.
- `I18N_SEL` покрывает текстовые узлы. Соседние `<em>`, атрибуты `alt` и строки, собираемые в JS, туда не попадают сами — при добавлении блока проверять, видит ли их словарь.
- `node-html-parser` не раскрывает HTML-сущности: ключ с `&mdash;` не совпадёт без раскрытия. В сборщике это учтено.

## Тайлы карты — переезд с CARTO на OpenStreetMap (31.08.2026)

CARTO закрыл доступ к своим базовым картам без ключа: сервер начал отдавать тайлы с надписью «API KEY REQUIRED» поверх изображения. Карта на живом сайте выглядела сломанной. Esri к тому же моменту тоже перешёл на ключи и отвечает 403.

- Теперь `https://tile.openstreetmap.org/{z}/{x}/{y}.png` — без ключа, лицензия ODbL, атрибуция «© участники OpenStreetMap» обязательна и стоит на обеих картах.
- Привычный светло-серый вид даёт CSS-фильтр на `.leaflet-tile-pane`, а не поставщик. Тёмная тема — инверсия с возвратом оттенка (`invert(1) hue-rotate(180deg)`), поэтому вода остаётся синеватой. Фильтр висит только на слое тайлов: маркеры, попапы и подписи под него не попадают.
- Из-за этого **при переключении темы адрес тайлов больше не подменяется** — раньше там был `setUrl` на dark_all/light_all. Не возвращать.
- ⚠️ У OSM есть политика использования: она рассчитана на умеренный трафик. Если посещаемость вырастет, переходить на своего поставщика с ключом (MapTiler, Stadia) или на свой прокси — но не молча, ключ придётся где-то хранить.

## Безопасность — проверка 20.08.2026

- **Приём заявок.** В воркере `if (origin && ...)` пропускал проверку при пустом `Origin` — кто угодно мог слать сообщения в Telegram обычным `curl`. Теперь `Origin` обязателен, плюс лимит 5 заявок с адреса за 10 минут. Код: `Продукция/Сайты/aktiv-upakovka/worker/worker.js`; воркер **общий с faktlab.ru** — после правок деплоить и проверять оба сайта.
- **Pages отдаёт из репозитория всё.** `CLAUDE.md` и `ROADMAP.md` открывались по прямой ссылке. Закрыто через `_config.yml`. Любой новый внутренний файл добавлять в `exclude`. `.nojekyll` не заводить — с ним исключения перестанут работать.
- **Внешние скрипты только с SRI.** Leaflet подключён с хешами; при смене версии пересчитывать, иначе карта не загрузится.
- Ждёт решения Евгения: CSP (нужен `unsafe-inline` из-за встроенных скриптов, есть риск убить Вебвизор), принудительный HTTPS в настройках Pages, 2FA у GitHub / Cloudflare / регистратора домена.
