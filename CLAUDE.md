# Амур Атлас — гид по Благовещенску (проектная память)

Одностраничный туристический сайт-гид по городу **Благовещенск (Амурская обл., Россия)** — на Амуре напротив китайского Хэйхэ. Автор проекта: ИИщенко LAB.

## Что это технически
- **`index.html`** — весь HTML, CSS и JS внутри. Сборки нет (никакого npm/build).
- **`lang-en.js`** — единственный доп. файл: словарь английских переводов `window.EN` (с 23.07.2026, мультиязычность RU/EN). Вынесен отдельно, чтобы не раздувать index.html и чтобы перевод правился изолированно. Подключён `<script src>` в head. Это осознанное послабление правила «единый файл» ради поддерживаемости словаря.
- Внешние зависимости только через CDN: Leaflet 1.9.4 (карта), тайлы CartoDB Positron, Google Fonts (Space Grotesk + Inter), фото с Wikimedia Commons.

## Мультиязычность (i18n) — как устроена
- Кнопка RU/EN в шапке, выбор в localStorage `atlas-lang`, ранний скрипт в head ставит `<html lang>` до отрисовки.
- Движок `applyLang` в index.html: обходит текстовые элементы по списку `I18N_SEL`, запоминает русский оригинал в `data-ru`, подменяет по совпадению текста из `window.EN`. **Нет ключа → остаётся русский (безопасный fallback), ничего не ломается.** Числа/цены не трогаются — они в отдельных классах (`.stat-num`, `.kpi`, `.hh-total .big` и т.п.), их нет в `I18N_SEL`.
- Ключ словаря = русский `innerHTML` элемента (со схлопнутыми пробелами). Значение — английский `innerHTML` (теги `<em>/<br>/<span>` сохраняются).
- **Статус:** переведён каркас (шапка, hero, заголовки/лиды всех секций, футер, метатеги). Глубокие тексты (карточки, FAQ, факты, кухня, история, Хэйхэ, канатка, сторителлинг) и **динамика** (попапы точек, план маршрута, события, калькулятор Хэйхэ — перерисовываются из JS-массивов) — дозаполняются в `lang-en.js` + хук `window.renderDynamicI18n`. Селекторы под них уже в `I18N_SEL`.

## Жёсткие правила (не ломать)
- Держим **единый `index.html`** без шага сборки. Новый JS/CSS — inline или через CDN-тег. Пути должны работать из корня Pages.
- **Не сломать существующее:** интерактивную карту (Leaflet), конструктор маршрута (`renderPlan`), ленту событий, счётчики, секцию «Любопытное».
- Светлая тема — по умолчанию; с 23.07.2026 есть тёмная (кнопка в шапке, `html[data-theme="dark"]` переопределяет токены, выбор в localStorage `atlas-theme`, тайлы карты переключаются light_all/dark_all). Токены в `:root` (`--bg #FAF8F3`, `--teal #0E9A93`, `--amber #E0872B`); служебные: `--on-ink` (текст на кнопках цвета --ink), `--nav-bg`, `--foot-bg`. Новые компоненты обязаны работать в обеих темах. Шрифты: Space Grotesk (заголовки) + Inter (текст).
- Палитра категорий карты — набор **Okabe-Ito (colorblind-safe)**: `--c-nat #009E73`, `--c-sea #2E9AD1`, `--c-his #C56AA0`, `--c-gas #E69F00`, `--c-spa #D55E00`, `--c-city #0072B2`. Менять — только сохраняя контраст.

## Структура данных (в `<script>` внизу)
- `POINTS[]` — 23 точки карты: `{id,name,lat,lng,cat,desc,img?}`. Категории: nat/sea/his/gas/spa/city.
- `ACT[]` — активности для конструктора маршрута (теги, интересы, сезон, стоимость).
- `FALLBACK_EVENTS[]` — встроенная афиша; Google Sheets подключается через `SHEET_CSV_URL` (публикация листа в CSV), парсер `parseCsv` в JS.
- `ERAS[]`, `DISHES[]` — история и кухня. Факты «Любопытного» — статичный HTML в секции `#facts`.
- Модель бюджета в `renderPlan()`: `дневной(бюджет×дни×чел) + проживание(ночи×номера×3800×сезон) + активности(Σ×чел) + дорога(чел×14000)`.

## Точность (важно — уже ловили ошибки)
- **Координаты точек — только из Wikidata (P625) / OpenStreetMap / Википедии, не на глаз.** Центр города и набережная — широта ~50.256–50.262 N.
- **Фото с Commons проверять по категории/описанию, не по имени файла** (были подмены: «собор Благовещения» → оказался Воронеж). Брать из категорий, привязанных к городу.
- **Любые цифры/годы сверять по источникам** перед публикацией.

## Рабочий цикл
- Одна фича за раз → просмотр `git diff` → коммит → проверка в браузере.
- Локальный предпросмотр: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.
- Визуальная проверка: через `claude-in-chrome` (скриншот localhost и глазами).
- **Деплой:** запушить в репозиторий (или на GitHub: Add file → Upload files, перезалить `index.html`) — Pages обновится за 1–2 минуты.
